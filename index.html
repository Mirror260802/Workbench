同步状态

同步状态

说明

同步规则

  • 整库同步：整个工作台的数据（记账 / 习惯 / 日程 / 收藏 / 收藏项 / 错题等）作为一条记录整体上传或下载，不拆分模块。
  • 同步槽位：云端按你这套 Supabase 配置（URL + Anon Key）自动派生的固定标识来区分数据，无需记忆或输入任何密钥。换设备时只要填同一套配置，即自动从云端拉取最新版本；打开或刷新页面时会先完成同步再解锁编辑，避免旧数据覆盖云端。
  • 先同步后编辑：打开页面会先弹出同步框并临时锁定所有编辑功能，待云端最新数据拉取完成、模态框自动关闭后才解锁；本地任一改动约 1.5 秒后自动上传，避免旧数据覆盖云端较新数据。换设备填同一套配置即自动从云端拉取最新数据并合并到本机，无须再手动点"立即同步"确认。
  • 静默运行：连接后无需手动触发、不需登录账号；同步在后台进行；未保存的草稿不会上传，关闭页面前自动保存后再上传。
  • 数据存于你自己的 Supabase 项目（匿名公钥 + URL 仅保存在本浏览器），不上传到任何第三方服务。

导入说明

记账/收藏 导入

支持 JSON 与 CSV 格式,自动识别表格头。新增不会覆盖现有数据,按规则去重。

① 选择文件

点击下方"选择文件"按钮,在弹出的文件选择器中选中你的 .json 或 .csv 文件即可。

② JSON 字段参考

  • 导出当前数据得到的是标准 JSON,直接用导出文件再导入可完整还原。

③ CSV 格式

第一行为表头(如 日期,金额,分类,备注),后续每行为一条记录。使用 UTF-8 编码。日期格式建议 YYYY-MM-DD。

④ 去重规则

记账:同日期+同流向+同分类+同金额+同备注视为重复。收藏:同名+同类型+同日期+同评分+同短评视为重复。重复项自动跳过。
